This is the SAME sentinel used for all runtime logs and is present in the diagnostic run. Therefore the gate is not independent of logging. ### R003-F02 — generic trampoline is not proven safe for its advertised domain (high)

cydiasubstrate_macos.m copies four instructions and appends `ldr x17; br x17`, while its only rejection class is PC-relative instructions. Source permits windows that establish x17 for later use (branch-back destroys that value), terminal/control-flow instructions, and unknown instruction classes. The 16-byte replacement is published in multiple stores after page permission changes; no serialization, thread-quiescence contract or original-pointer publication ordering is enforced. A failed final RX vm_protect is ignored. Returned original is NULL on refusal, but callers often treat MSHookFunction as an infallible void API and log installed regardless.

These are unsupported contracts identified from source, not claims of observed device crashes. A toy function returning 42 does not cover them. For the next experiment use a bounded debugger trace or constrain the experimental hook to exact UUID + validated prologue + known startup/quiescence scope; do not present it as a general MSHookFunction repair. If implementing generic support, prove relocation/register preservation, publication/rollback/protection semantics and audit callers; exercise meaningful negative/control-flow cases and both arm64/arm64e.
